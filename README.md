# أدوات حسام | Hassam's Tools
**By [Hassam](https://github.com/hosam382)**

**الموقع:** https://hosam382.github.io/

![أدوات حسام](og.png)

معرض للأدوات العربية مفتوحة المصدر اللي أبنيها، بتصميم حبر وطباعة: تمسح على الاسم بالماوس أو بإصبعك فينصبغ بالحبر، والأدوات فهرس مثل المجلات، تضغط على أي سطر ويفتح لك وش تسوي الأداة وعدد اختباراتها ورابط تجربتها وكودها.

| الأداة | المستودع |
|---|---|
| مهارات Claude بالعربي | [arabic-claude-skills](https://github.com/hosam382/arabic-claude-skills) |
| مكتبة أوامر الذكاء الاصطناعي للمعلم | [ai-prompts-for-teachers](https://github.com/hosam382/ai-prompts-for-teachers) |
| حاسبة النسبة الموزونة | [weighted-percentage-calculator](https://github.com/hosam382/weighted-percentage-calculator) |
| فاحص قوة كلمة المرور | [password-checker-ar](https://github.com/hosam382/password-checker-ar) |
| جدول مذاكرة القدرات والتحصيلي | [study-plan-generator](https://github.com/hosam382/study-plan-generator) |
| أدوات النص العربي (Python) | [arabic-text-toolkit](https://github.com/hosam382/arabic-text-toolkit) |

الصفحة HTML و CSS و JavaScript بدون أي مكتبة، والخطوط محفوظة داخل المستودع، فما تطلب شي من برّا ولا فيها تتبّع. وبدون جافاسكربت تظهر كل الأدوات تحت بعض.

## English
A small portfolio of my Arabic open-source tools with an ink-and-print look: paint red ink over the calligraphic name with your mouse or finger, then browse the tools as a magazine-style index where each row opens what it does, its test count, and links to try it and read the code. Plain HTML/CSS/JS, self-hosted fonts, no trackers.

بُني بمساعدة الذكاء الاصطناعي (Claude) وراجعه حسام.
Built with AI assistance (Claude), reviewed by Hassam.
